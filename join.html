Java版の手順統合版の手順

Java Edition

Java版の参加手順

  1. Minecraft Java Edition を起動する

    Minecraft Launcher を開き、「Java Edition」を選んで「プレイ」を押します。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  2. 「マルチプレイ」を選ぶ

    タイトル画面で「マルチプレイ」をクリックします。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  3. 「サーバーを追加」を押す

    サーバー一覧の画面で「サーバーを追加」をクリックします。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  4. サーバー情報を入力する

    「サーバー名」には好きな名前（例：白熊鯖）、「サーバーアドレス」には上の表の「Java版アドレス」を入力します。入力して「完了」を押します。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  5. サーバーに接続する

    一覧から白熊鯖を選び、「サーバーに接続」を押します。接続できない場合は、Minecraftのバージョンが「対応バージョン」と合っているか確認してください。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

Bedrock Edition

統合版の参加手順

統合版からの接続可否は、サーバー側の設定を確認できるまで案内できません。対応状況が確定した時点でこのページに掲載します。

  1. Minecraft（統合版）を起動する

    お使いの端末でMinecraftを起動し、「プレイ」を選びます。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  2. 「サーバー」タブを開き、サーバーを追加する

    一覧の下部にある「サーバーを追加」を選びます。※ 画面の表示は機種やバージョンによって異なります。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  3. アドレスとポートを入力する

    「サーバー名」に好きな名前、「サーバーアドレス」に上の表の「統合版アドレス」、「ポート」に「統合版ポート」を入力して保存します。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定

  4. サーバーに接続する

    一覧から白熊鯖を選んで参加します。

    スクリーンショット準備中実際の画面を assets/images/guide/ に追加予定
